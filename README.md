# diabetes-prediction-ml

An educational machine learning project that predicts diabetes using a classification model.

## Dataset
Source: Kaggle - https://www.kaggle.com/datasets/...

## Libraries
- pandas
- scikit-learn

## How to Run
1. Download both projex.py and diabetes.csv into the same folder.
2. Install the libraries: pip install pandas scikit-learn
3. Run: python projex.py

## Results
Model accuracy: 72%

## Disclaimer
This project is for educational purposes only and is not a medical diagnostic tool.
